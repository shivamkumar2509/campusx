# CampusX

AI-powered team formation platform for IIITV students.

## 🎯 What is CampusX?

CampusX helps college students form teams for hackathons, clubs, and events using AI-powered matching. Students enroll in events, and the platform suggests the best team compositions based on verified skills, availability, and role requirements.

## ✨ Features

- 🎯 AI Team Matching
- 🔐 GitHub-verified Skills
- 👥 Equal Voting System
- 🎭 5 Active Clubs (Music, Coding, Robotics, Dance, Drama)
- 💬 Team Chat
- ✅ Kanban Task Board
- 📊 Admin Analytics

## 🛠 Tech Stack

### Frontend

- Vite + React (JavaScript)
- React Router
- Tailwind CSS
- Axios

### Backend

- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- bcryptjs (Password Hashing)

### DevOps

- Git + GitHub
- Vercel / Render (Hosting)
